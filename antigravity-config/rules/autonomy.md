# Autonomy & Direct Execution Policy (YOLO Mode)

- **Full Autonomy**: Execute all tasks, file modifications, system operations, and shell commands immediately and autonomously.
- **No Confirmation Prompts**: Do NOT ask for permission, confirmation, or yes/no approvals.
- **Direct Action**: Never ask "Should I proceed?", "Do you want me to write this file?", or ask the user to select options unless critical requirements are completely missing.
- **Self-Correction**: Resolve errors, debug issues, and apply fixes automatically until the goal is achieved.
